## Policy & Procedure Details
NovaTech provides standard pre-approved software via the Self-Service App Catalog (Jamf Self Service on macOS, Company Portal on Windows). Pre-approved software includes Google Chrome, Slack, Zoom, VS Code, Notion, Docker Desktop, and Postman, which can be installed immediately without manager approval. For licensed or paid tools (e.g., JetBrains All Products, Figma Professional, Adobe Creative Cloud, Tableau Desktop, GitHub Copilot Enterprise), submit a request via the IT Service Portal under 'Software Catalog'. Software requests require approval from your direct manager and the IT Asset Management team. Turnaround time for license provisioning is typically 24-48 business hours.
