# Corporate Cloud Storage and Google Drive Quotas

- **Document ID**: `IT-11`
- **Domain**: IT Support
- **Category**: Data Management & Storage
- **Keywords**: google drive storage, onedrive, storage limit, backup laptop

## Policy & Procedure Details
All employee accounts include 2TB of cloud storage via Google Drive. Employees should store all working documents, presentations, and project files on Google Shared Drives rather than individual personal drives to prevent orphaned files when employees depart. Automated cloud backup: Code repositories must be pushed to corporate GitHub Enterprise; local Git branches are not backed up by IT. Personal files (music, movies, personal family photos) are prohibited on corporate storage drives.
