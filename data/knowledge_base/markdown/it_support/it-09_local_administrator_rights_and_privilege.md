# Local Administrator Rights and Privilege Management (Admin By Request)

- **Document ID**: `IT-09`
- **Domain**: IT Support
- **Category**: Security & Compliance
- **Keywords**: admin rights, sudo access, admin by request, root access

## Policy & Procedure Details
In compliance with SOC2 Type II and ISO 27001 standards, permanent local administrator / root privileges are disabled on all corporate endpoints. If you need elevated permissions to install developer libraries, configure Docker, or modify system settings: 1. On macOS: Open 'Admin By Request' from your menu bar and select 'Request Administrator Access'. Provide a valid business reason. Elevated sessions are auto-approved for pre-authorized developer tools for up to 30 minutes. 2. On Windows: Right-click the installer and choose 'Run with Admin By Request'. Session activities are audited and logged for compliance.
